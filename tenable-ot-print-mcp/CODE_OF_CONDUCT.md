# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give the benefit of the doubt, focus on the
work. Harassment, insults, or discriminatory comments aren't tolerated
in any project space (issues, pull requests, commits, chat, email).

To report an unacceptable interaction, contact:

  **dstorey@barossafarm.com**

Reports are confidential. They'll be investigated and acted on
appropriately to the severity, up to and including removing offenders
from the project.
